SOBRE O PROJETO

Descubra seu próximo anime

O AniMatch é uma extensão independente que combina recomendações da comunidade, duração e gêneros para ajudar você a encontrar sua próxima série.

O perfil público é consultado pela API GraphQL do AniList. Para listas privadas, a autorização é feita diretamente pelo AniList.
